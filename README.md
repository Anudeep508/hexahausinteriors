
# HEXAHAUS Website

## Hosting on GitHub Pages

1. Create GitHub repository
2. Upload all files
3. Go to:
   Settings → Pages
4. Source:
   Deploy from branch
5. Select:
   main branch / root
6. Save

Your website will be live in a few minutes.

## Google Sheets Integration

Open:
js/main.js

Replace:

PASTE_GOOGLE_SCRIPT_URL_HERE

with your Google Apps Script deployment URL.
